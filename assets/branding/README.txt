Vāk starter brand assets

svg/ = editable scalable vector logo files
png/ = icon sizes and monochrome symbol variants
ico/vak.ico = Windows application icon

Use vak-logo-dark.svg on dark backgrounds and vak-logo-light.svg on light backgrounds.
Use vak-icon-*.png for UI places that accept PNG. Use vak.ico for Windows app/window icon.

These are starter assets and can be refined after checking them inside the actual app.
The SVG wordmark uses a system font stack, so its exact font appearance may vary by machine.
